Criteria

What actually gets a spot in the library, and why some real submissions don't make it. Plain, short, no filler.

The bar

An entry has to clear all four:

  • It's a real GitHub repo — not a product page, not a landing page for something closed-source, not a demo video with no code behind it.
  • There's something to actually open. A README that explains what it does, code or content a visitor can read, clone, or use today — not just a name and a star count.
  • It genuinely fits one of the six tags — AI & Agents, Design & Visual Tools, Data Visualization, Creative Coding, Video & Motion, Agent Practice. If it takes real force to make it fit, it doesn't belong yet; a seventh tag gets added the same way Agent Practice was — when real content justifies it, not designed in ahead of time.
  • It isn't already here. Checked against the whole library, not just this week's batch — same dedup logic that runs on every automated entry.

What doesn't make it

Star count isn't a criterion by itself — a small, genuinely useful find belongs here the same as a big one, and a repo with thousands of stars still gets skipped if it's off-topic or there's nothing real to point at. What actually disqualifies an entry:

  • Invented or padded — this library's whole premise is that every entry is real. One fake one breaks that for all of them.
  • Abandoned with no real content — a placeholder repo, a stub, a link to somewhere else.
  • Off-topic — doesn't fit any of the six tags, even loosely.
  • Spam or self-promotion with nothing behind it.

Automated scan vs. your submission

The library updates two ways, and they're not held to the same review standard on purpose. A nightly scan searches GitHub directly, already filtered to the six tags, and publishes straight to the library with no human step in between — real data, pre-filtered by topic, lower stakes than a stranger's claim. A submission through the form below skips that pre-filtering entirely, so every one gets read by hand before anything's added. That's not a formality — it's the actual difference between the two paths.

After you submit

No account or email is collected, so there's no way to notify you either way — the only signal is the library itself. If it clears the bar, it shows up there, tagged, with its own permalink. If it doesn't, nothing happens, and that's fine — most real, useful repos still won't fit six tags and a dedup check on the first try.
