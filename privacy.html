Privacy

What gggggit actually collects, why, and how to have it removed. Plain, short, no filler.

What's collected

Two separate things, neither shared with the other:

If you sign in with GitHub (to heart entries): your GitHub id, username, avatar, and whatever heart button you click. Which repos you've hearted is private — visible only to you. The total heart count per repo is public.

If you sign up for update notifications (footer form): your email address, and a timestamp of when you asked to be notified. Nothing else.

Why

The GitHub sign-in exists so hearting can actually persist per person. The email signup is for eventually notifying you about new library additions — sending isn't built yet, so nothing is emailed to this address today. It won't be used for anything else once it is.

How it's protected

Both are stored in a Postgres database with row-level security enforced by the database itself, not just application code. Your individual heart list and your email address are never exposed through gggggit's public API — the only public number is the aggregate heart count per repo, which never reveals who hearted what.

Removal

Email hello@paschkastudio.com with the address or GitHub account in question and it comes out. No form, no waiting on a vendor — this is a small, self-run database, not a platform.

Third parties

Data lives in Supabase (the database/auth provider) and, if you sign in with GitHub, GitHub's own OAuth flow (governed by GitHub's privacy statement). Nothing here is sold, and none of it is used for advertising.

gggggit is built and run by Alexander Paschka, independently of any client work.
